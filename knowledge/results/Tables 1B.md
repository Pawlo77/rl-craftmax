# Tables 1B

Each file holds the rows of this benchmark only; the CSV is in `outputs/results/tables/1b/`, the LaTeX table in `report/tables/1b/`. Generated by `make figure-notes` from the `captions.csv` of the folder.

## S5

| Table | Description |
|---|---|
| `outputs/results/tables/1b/scale_compute.csv` | **Score per compute.** Mean final score against wall-clock hours per profile with the Pareto front; laptop timings are context only. |

## Main results

| Table | Description |
|---|---|
| `outputs/results/tables/1b/main.csv` [main.tex](../../report/tables/1b/main.tex) | **Main results.** Final score of every tuned method (and control) per block: mean with s.e., IQM or median with 95% bootstrap CIs, the final-checkpoint eval means, and against each control the probability of improvement with Holm-adjusted p. |

## Literature

| Table | Description |
|---|---|
| `outputs/results/tables/1b/literature.csv` [literature.tex](../../report/tables/1b/literature.tex) | **Literature comparison.** Our rows beside the published rows of the comparable score kind, with our CI and the reproduction-gate status of the controls; published rows keep their protocol, seeds and spread as copied. |
| `outputs/results/tables/1b/reproduction_gate.csv` | **Reproduction gate.** Each control's final score against its published value: pass or fail with the gap and the band half-width h. |

## Stability

| Table | Description |
|---|---|
| `outputs/results/tables/1b/stability.csv` | **Stability.** Seed sd and CV of the final score and, per run with a score curve, the deepest drawdown, drops and collapses. |
| `outputs/results/tables/1b/stability_runs.csv` | **Stability per run.** The per-run part of the stability table: deepest drawdown, any drop and collapse of each tuned run with a score curve. |

## Hardware

| Table | Description |
|---|---|
| `outputs/results/tables/1b/hardware.csv` | **Hardware.** Run medians per hardware profile (steps per second, wall-clock, compile time, memory, utilisation); profiles are never compared, laptop timings are context only. |

## Stability and hardware

| Table | Description |
|---|---|
| [stability_hardware.tex](../../report/tables/1b/stability_hardware.tex) | **Stability and hardware.** Seed sd, drawdown, drops and collapses beside steady steps per second, wall-clock and memory, per profile and block (LaTeX table). |

## In-game

| Table | Description |
|---|---|
| `outputs/results/tables/1b/game_summary.csv` [game_summary.tex](../../report/tables/1b/game_summary.tex) | **In-game summary.** Per method: race wins, deepest floor, most frequent cause of death, coverage, wasted share and adoption of the advanced mechanics. |
| `outputs/results/tables/1b/race.csv` | **First-unlock race.** Median first unlock of every achievement per method (env steps and wall-clock) with the eligibility rule and the winners, per block. |

## T8

| Table | Description |
|---|---|
| `outputs/results/tables/1b/speed.csv` | **Learning speed.** Per method, the seed medians of the mean score over the budget (auc), the budget share at 50 % and 90 % of the final score (to_50, to_90) and the score gained over the last 20 % of the budget, with the runs that still plateau. |
