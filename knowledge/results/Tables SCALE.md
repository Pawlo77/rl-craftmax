# Tables SCALE

Each file holds the rows of this benchmark only; the CSV is in `outputs/results/tables/scale/`, the LaTeX table in `report/tables/scale/`. Generated by `make figure-notes` from the `captions.csv` of the folder.

## S1

| Table | Description |
|---|---|
| `outputs/results/tables/scale/scale_flips.csv` | **Flipped pairs.** Method pairs whose mean order differs between 1M and 1B, with the difference and its CI at each budget. |
| `outputs/results/tables/scale/scale_rank.csv` | **Rank agreement.** Spearman and Kendall correlation between the 1M and 1B method means with bootstrap CIs that resample the seeds of both budgets. |

## S2

| Table | Description |
|---|---|
| `outputs/results/tables/scale/scale_advantage.csv` | **Advantage over the control.** Gain over the base control in percent at 1M and 1B and its change, with bootstrap CIs; a change interval holding 0 leaves the 1M advantage open. |

## S3

| Table | Description |
|---|---|
| `outputs/results/tables/scale/scale_scaling.csv` | **Scaling.** Log of the 1B to 1M mean ratio per method with a bootstrap CI. |

## S4

| Table | Description |
|---|---|
| `outputs/results/tables/scale/scale_precision.csv` | **Precision at 3 seeds.** CI half-widths at both budgets and the smallest difference 3 seeds resolve (Welch test, power 0.8, 1M seed sd). |

## S6

| Table | Description |
|---|---|
| `outputs/results/tables/scale/scale_transfer.csv` | **Tuning transfer.** The 1M tuning optimism beside the change of the advantage at 1B; 1B has no tuning of its own. |
