# Figures 1M

Every figure is one panel in one PNG without text beyond axes, ticks and a legend where one is needed; this note holds what the report prints around them. Colours, line styles and markers of the methods: `legend_methods`. Generated by `make figure-notes` from the `captions.csv` of each folder.

## Comparison

### Method legend

| Figure | Description |
|---|---|
| `report/figures/1m/legend_methods.png` | **Method legend.** Colour, line style and marker of every method; the other figures carry no method legend. Controls are dashed with their own marker, tuned methods solid, an ablation of a method dotted with a hollow marker in the method's colour. |

### Learning curves

| Figure | Description |
|---|---|
| `report/figures/1m/curves_score_main.png` | **Training score, main block.** Mean training score (% of the maximum) over environment steps: the controls (dashed) and tuned methods. Band: 95% bootstrap CI over seeds; both blocks share axes. |
| `report/figures/1m/curves_score_skills.png` | **Training score, uses hand-written skills block.** Mean training score (% of the maximum) over environment steps: the controls (dashed) and the methods that use hand-written skills. Band: 95% bootstrap CI over seeds; both blocks share axes. |

### Aggregate scores

| Figure | Description |
|---|---|
| `report/figures/1m/aggregate.png` | **Final score per method.** Final training score (% of the maximum) of each method: IQM (circle) and mean (diamond) over seeds with 95% bootstrap CIs (one whisker each). Main block on top, the methods that use hand-written skills below with the controls repeated; each ablation is a dotted, hollow row under its method and is never pooled with it. |

### PoI matrix

| Figure | Description |
|---|---|

| `report/figures/1m/poi_matrix_skills.png` | **Probability of improvement, uses hand-written skills block.** P(row score > column score) over seed pairs, blue above 0.5; bold: the 95% bootstrap CI excludes 0.5.
